# Soundtrack files

The global soundtrack player reads these bundled files directly:

- `time.mp3`
- `no-time-for-caution.mp3`
- `cornfield-chase.mp3`
- `can-you-hear-the-music.mp3`

Keep the files in this `public/audio` directory when building or deploying. The player persists across chapter navigation and advances through the list automatically. Browser autoplay rules still require the visitor to click Play once before sound begins.
